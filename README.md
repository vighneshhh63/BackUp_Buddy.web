Problem Statement

Most users are aware that data backup is important, but they don't do it consistently. The main barriers aren't lack of tools — it's forgetfulness, backup being seen as a tedious/manual task, and (for a less tech-comfortable segment) simply not knowing how to start. As a result, users experience real, stressful data loss (photos, documents, even legal certificates) that could have been prevented with a simple nudge or guided process.

Proposed Solution: "BackupBuddy" — a web app which has interesting backup tools like reminders, risks etc.
